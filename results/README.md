# Results

`reported_2021.csv` — mean/min/max accuracy over 20 stratified 30% test subsamples, **copied from the original
capstone README**. These were produced in 2021 by the notebooks in `notebooks/legacy/` and have **not been re-run**
by this repository (the transcripts and label decoder are not distributed). They are accuracy only, from a single
training run per configuration, on the natural (imbalanced) test distribution.

Anything you generate locally lands in `runs/` and `results/comparison*.csv`, which are git-ignored.
